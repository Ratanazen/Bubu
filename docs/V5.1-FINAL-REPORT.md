*   **IPC Unix Domain Socket Daemon (`bubu.sock`)**: Stable background execution and CLI communication.
*   **Bubu Desktop Companion CLI**: `bubu start`, `bubu stop`, `bubu status`, `bubu pet hide`, `bubu settings`, `bubu say`.
*   **Native Screen Detection**: Full multi-monitor boundary handling and collision detection.
*   **Context Profile Engine**: App monitor, automatic context switching, and lyrics integrations.
*   **Dynamic Avatar Rendering**: Transitioned from procedurally generated SVGs to generic animated character support (`SkinManager`).
*   **Notification Engine (Speech Bubbles)**: Custom renderer for pill-shaped notifications and CLI speech dispatch.
*   **Settings Interface**: Centralized Control Center architecture.
*   **Diagnostics Tools**: `bubu diagnostics` and `bubu config check`.

## 3. Known Limitations (Post-Release)
*   **Wayland Global Shortcuts**: True global hotkeys are still experimental in some strict Wayland compositors (Sway/Niri) without dbus integration.
*   **macOS / Windows**: Core engine supports these platforms, but manual QA packaging verification is still required.
